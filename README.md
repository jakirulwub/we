# Akkcento — luxury fine jewelry

A polished, responsive one-page atelier site for Akkcento bespoke engagement rings and wedding bands.

## Run locally

This implementation is framework-free and can be previewed by opening `index.html` directly, or served with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive luxury editorial layout
- Data-driven engagement ring and wedding band collection
- Category filtering and accessible quick-view modal
- Bespoke process and atelier storytelling sections
- Consultation form with client-side validation and success state
- Responsive navigation, semantic structure, SEO metadata, focus states, and reduced-motion support
- Replaceable Unsplash image URLs centralized in `script.js` and the image markup in `index.html`

The consultation form is intentionally front-end only until a form endpoint or CRM integration is selected.
